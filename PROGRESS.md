### What was built
- **Desktop app (Tauri v2 + React 19 + TS strict + Tailwind v4).** Window 1280×820 (min 960×620), bundle id `com.machi.app`, Machi icon.
- **Rust core (`crates/machi-core`):**
  - keychain secrets with a debug-only `.env` fallback;
  - SQLite store with migrations (conversations, message trees, attachments, settings, model cache, local telemetry);
  - one OpenAI-compatible provider adapter (Mixroute primary; OpenAI, Anthropic, Gemini, DeepSeek and OpenRouter optional) with SSE streaming, cancellation and 429 backoff ending in a typed `RateLimited` error;
  - model catalog from `config/models.toml` merged with the live `/models` list (cached 24 h);
  - chat service: tree context, model switching, stop, edit/regenerate branches, compare, auto titles;
  - export (Markdown/JSON) and delete-all.
- **Bindings:** 28 typed Tauri commands, with TypeScript bindings generated by tauri-specta.
- **UI (§15):** tokens + primitives + `/gallery`, icon rail + pinnable chats flyout, home (wordmark, chips, composer, Models row, first-run card), chat view (virtualized, Markdown/Shiki/KaTeX, actions, branches, inline errors), composer with attachments, "@" for one message and per-chat settings, cmdk model picker, compare columns, Models page, two-column Settings, global search, keyboard shortcuts, light/dark themes and text size.
- **Tests:** 97 Rust (fixtures only, no live calls), 118 Vitest (incl. WCAG AA contrast for every token pair and a 200-message virtualization test), 28 Playwright (flows + screenshots on the mock backend). Live checks: `cargo run --example smoke` and `cargo run --example live_chat`.

### How to run
- Dev app: `pnpm install` once, then `pnpm tauri dev` (debug builds read `MIXROUTE_API_KEY` from `.env`).
- Browser preview with the mock backend: `pnpm dev`, then open http://localhost:1420 (`#/gallery` shows the design system).
- Checks: `pnpm lint && pnpm typecheck && pnpm test && pnpm e2e`, `cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`.
- Live checks (uses the key, prints no secrets): `cargo run --example smoke`, `cargo run --example live_chat`.
- Release: `pnpm tauri build --bundles app` → `target/release/bundle/macos/Machi.app`. Release builds never read `.env`, so add the key on the first-run card (it's stored in the keychain).
